# 内置技能详情

所有内置技能按依赖展开后的顺序在同一浏览器会话中执行。截至 2026-10-19，月卡、邮件、纪行、成就和活动奖励均已在真实账号环境完成全流程验收，并且默认全部启用；探索派遣保持关闭和暂停状态。

每个内置奖励技能在领取动作后都有一个 `screenshot` 检查点，成功运行会在 `~/.giclaw/data/screenshots/` 留下效果图；步骤失败（包括超时）也会先保存失败现场。共享的原神知识由 16 个 `context: true` 上下文技能按标签注入，见[上下文技能](./context-skills.md)。

## welkin-moon — 月卡每日领取

- **ID**: `welkin-moon`
- **说明**: 登录 → 启动游戏 → 领取月卡奖励
- **超时**: 10 分钟（`600000ms`）
- **自动重试**: 关闭
- **验收**: 真实账号全流程已通过

### 执行顺序

**必须排在第一个。** 此技能负责打开云原神页面、完成登录流程、启动游戏。后续所有技能都依赖它建立的游戏内会话。

### 前置条件

- 账号可以正常进入云游戏平台；没有有效 Cookie 时程序会自动打开可见浏览器引导登录
- 已购买月卡时会领取当日奖励；没有奖励弹窗时继续完成游戏启动流程

### 已知限制

- 云原神可能出现排队等待，技能会自动等待排队完成
- 平台画质新手引导（“点击此处修改游戏画质 / 下一步(1/3)”）是非阻塞覆盖层；点不动时忽略并继续，不要反复点击
- 云加载/排队可能超过单步视觉等待的 180s 上限；等待超时不等于技能逻辑错误，可拆成多个等待步骤后重试
- 启动后可能出现网络错误、用户协议、登录入口或新手引导；任务会把这些页面识别为可继续状态并按顺序处理，避免等待动作与后续点击互相阻塞
- 如果游戏画面长时间无响应（如 canvas 未激活），可能需要点击激活
- 单个视觉等待最多持续 3 分钟并每 15 秒报告进度；网络波动或排队时间超过该上限时会停止当前运行，建议在网络稳定时重试

## claim-mail — 邮件领取

- **ID**: `claim-mail`
- **说明**: 打开邮箱 → 一键领取所有附件
- **超时**: 5 分钟（`300000ms`）
- **自动重试**: 关闭
- **验收**: 真实账号全流程已通过

### 执行顺序

声明了 `dependsOn: [welkin-moon]`，即使单独选择也会自动先启动游戏。

### 前置条件

- 游戏已启动并进入主界面（由 `welkin-moon` 完成）

### 已知限制

- 工作流会打开邮箱并检查底部“全部领取”按钮；按钮为灰色或邮件列表为空时不执行领取
- 邮件入口只在派蒙菜单面板内识别，不点击屏幕最左侧云游戏平台栏；误入云平台面板、名片或拍照界面时会关闭并返回菜单重新识别
- 必须先看到游戏内“邮箱”标题并通过界面断言，才会检查“全部领取”按钮
- 领取附件后可能弹出物品展示弹窗，技能会自动关闭
- 如果误入其他界面，工作流会退出后重新确认主界面状态

## battle-pass-claim — 纪行奖励领取

- **ID**: `battle-pass-claim`
- **说明**: 打开纪行 → 领取可领取的等级奖励
- **超时**: 5 分钟（`300000ms`）
- **自动重试**: 关闭
- **默认**: 启用
- **验收**: 真实账号全流程已通过

### 执行顺序

声明了 `dependsOn: [welkin-moon]`，运行时会自动先启动游戏。

### 前置条件

- 游戏已启动并进入主界面

### 已知限制

- 当前工作流从游戏菜单通过视觉确认「纪行」入口，不再依赖固定入口坐标
- 纪行界面有多个标签页（纪行任务、纪行之证等），需要确保在奖励领取页面
- 只领取已解锁（亮起）的奖励，灰色未解锁的会跳过
- 版本更新后纪行可能重置，界面布局可能变化
- 领取奖励后的物品展示弹窗需要关闭

## claim-event-rewards — 活动奖励领取

- **ID**: `claim-event-rewards`
- **说明**: 打开活动总览 → 领取明确已解锁的奖励
- **默认**: 启用
- **依赖**: `welkin-moon`
- **验收**: 真实账号全流程已通过

活动 UI 版本变化频繁。工作流只点击明确可领取的已解锁奖励，并明确禁止购买、消耗原石和进入挑战。版本更新后首次回归仍建议使用可见模式观察。

### 已知限制

- 活动可能打开外部 `act.mihoyo.com` 页面；该页面不属于游戏内领取流程，自动化不应在其中停留。真实运行中曾因外部页面卡住而耗尽任务超时。
